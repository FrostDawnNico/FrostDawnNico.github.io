理解图形学相关原理

渲染顺序

渲染Object顺序：

  1. 先渲染所有不透明（Opaque）
  2. 后渲染所有透明（Transparent）
  3. 不透明：从前到后渲染（近→远）
  4. 透明：从后到前渲染（远→近）

为什么要分顺序？

  1. 深度缓冲（Depth Buffer）

Unity 有个深度图，记录屏幕上每个像素最近的物体距离。

● 远处物体被近处物体挡住 → 直接不画，节省性能。

● 这个机制只对不透明物体生效。

  1. 不透明（Opaque）

● 有深度写入 ZWrite On

● 有深度测试 ZTest LEqual

● 规则：谁近画谁，远的直接被遮挡丢弃

● 渲染队列值：Queue = 2000

  1. 透明（Transparent）

● 关闭深度写入 ZWrite Off（关键！）

● 保留深度测试 ZTest LEqual

● 规则：不能遮挡自己，必须按“远→近”混合颜色 ● 渲染队列值：Queue = 3000

Rendering Path

渲染路径：将场景物体渲染到渲染纹理的过程中所使用的步骤和技术。

常见的Rendering Path：

Forward Shading

Deferred Shading

Forward变种

Deferred变种

Forward Shading

是最简单也最广泛支持的一种渲染技术，它的实现思想是遍历场景的所有物体，每个物体调用一次绘制指令，经由渲染管线光栅化后写入渲染纹理上。

优点：
1。实现简单
2。无需 MRT 的支持，硬件支持广泛
3。完美地支持 MSAA抗锯齿。

缺点：
1。 无法支撑大型复杂附带大量光源的场景渲染， 冗余计算多，过绘制严重

for each(object in ObjectsInScene){
    color=0;
    for each(light in LightsInScene){
        color += light.Shade(object);// for all lights, huge cost when the number of lights is huge
    }
    WriteColorRenderTarget(color);
}

Deferred Shading

是一种基于屏幕空间着色的技术，也是最普遍的一种渲染路径（Rendering Path）技术。它的核心思想是将场景的物体绘制分离成两个Pass：几何Pass和光照Pass，目的是将计算量大的光照Pass延后，和物体数量和光照数量解耦，以提升着色效率。在目前的主流渲染器和商业引擎中，有着广泛且充分的支持。

几何通道（Geometry Pass）将场景的物体信息光栅化到多个GBuffer中。这个阶段将场景中所有的不透明物体（Opaque）和Masked物体用无光照（Unlit）的材质执行渲染，然后将物体的几何信息写入到对应的渲染纹理（Render Target）中。

其中物体的几何信息有：
1、位置（Position，也可以是深度，因为只要有深度和屏幕空间的uv就可以重建出位置）。
2、法线（Normal）。
3、材质参数(Diffuse Color, Emissive Color, Specular Scale, Specular Power, AO, Roughness, Shading Model, …)。

注意：几何通道阶段不会执行光照计算，从而摒弃了很多冗余的光照计算逻辑，也就是避免了很多本被遮挡的物体光照计算，避免了过绘制（Overdraw）。

void RenderBasePass(){
    SetupBuffer();//设置集合数据缓冲区
    //遍历场景的非半透明物体
    for each(object in ObjectsInScene){
        SetUnlitMaterial(Object); //设置无光照的材质
        DrawObjectToBuffer(Object);//渲染几何信息到GBuffer，通常在GPU光栅化中完成
    }
}

光照通道（Lighting Pass）利用GBuffer的几何信息计算每个像素的光照结果，它的核心逻辑是遍历渲染分辨率数量相同的像素，根据每个像素的UV坐标从GBuffer采样获取该像素的几何信息，从而执行光照计算。

void RenderLightingPass(){
    BindGBuffer();//绑定集合数据缓冲区
    SetupRenderTarget();//设置渲染纹理
    //遍历RT所有像素
    for each(pixel in RenderTargetPixels){
        //获取GBuffer数据
        pixelData = GetPixelDataFromGBuffer(pixel.uv);
        color=0;
        for each(light in LightsInScene){
            color += CalculateLightColor(light,pixelData);//for all lights
        }
        WriteColorRenderTarget(color);
    }

}
