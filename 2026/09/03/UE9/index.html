源码自学积累

Python 字符串格式化（String Formatting）

CATALOG_ASSET_PATH = “{0}/{1}”.format(CATALOG_PACKAGE, CATALOG_ASSET_NAME)

“{0}/{1}” 是一个模板字符串，里面的 {0} 和 {1} 叫做占位符。

.format(…) 是 Python 的字符串方法，它会把括号里的变量，按顺序填进前面的占位符里。

Unreal Engine 的虚拟文件系统（Virtual File System）​ 和 资源注册表（Asset Registry）​ 的工作机制

/Game/ 是 Unreal Engine 预先定义好的一个“虚拟根目录”（挂载点），它自动映射到你当前打开的 Unreal 项目里的 Content 文件夹。

引擎在启动时会建立几个“挂载点（Mount Point）”，其中最重要的两个是：

/Game/​ 👉 映射到 当前项目的 Content 文件夹。

/Engine/​ 👉 映射到 Unreal 引擎安装目录下的 Engine/Content 文件夹（存放引擎自带资源）。

所以，当你写下 /Game/Characters/… 时，UE 看到 /Game/ 就知道：“哦，这是要操作当前这个项目的内容。”
