左值与右值

左值：可寻址、有名字的表达式，如变量。

int a = 10;   // a 左值
string s = "abc"; // s 左值

右值：临时值、无名字、不能取地址、用完即销毁，如函数返回值。

10 + 20;
string("hello"); // 临时对象
func_return_obj(); // 函数返回临时对象

左值引用与右值引用

左值引用 T&：给有名字、持久的变量起别名，不能绑临时值。
右值引用 T&&：给没名字、临时的值起别名，只能绑临时值，实现移动语义，目的：偷资源，不拷贝

左值引用是“借用”不拥有资源，只是给别人的变量起别名。
右值引用是“接管 / 偷”临时对象马上要销毁了，右值引用把它的内存、资源抢过来自己用，不用重新分配，性能极高。

代码示例

int a = 10;        // a 是左值
int& ref = a;      // ✅ 左值引用 绑定 左值

// int& ref = 10;  // ❌ 错误！不能绑定临时值

int&& rref = 10;   // ✅ 右值引用 绑定 临时右值

int a = 20;
// int&& rref = a; // ❌ 错误！不能绑定左值
