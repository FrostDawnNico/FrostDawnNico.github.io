STL容器的数据结构和算法

一、STL 容器必考

1️⃣ vector

底层结构

  • 连续内存动态数组
  • 本质是：T* + size + capacity

关键机制

点 面试标准答法
扩容 2 倍或 1.5 倍
扩容代价 O(n)，拷贝 + 释放旧内存
size vs capacity size 是元素个数，capacity 是已分配空间
push_back 可能触发 reallocate
emplace_back 原地构造，少一次拷贝

✅ 经典追问

vector 扩容为什么不用 2 倍以上？

  • 避免无法复用旧内存（某些实现用 1.5 倍）

2️⃣ map / set（红黑树）

底层结构

  • 红黑树（自平衡二叉搜索树）

特点

项目 说明
是否有序 ✅ 中序遍历有序
查找 O(log n)
是否稳定 ✅ 插入顺序不影响结构
迭代器失效 不会因插入/删除失效（除当前节点）

✅ 常考对比

map vs unordered_map（见下）

3️⃣ unordered_map / unordered_set

底层结构

  • 哈希表（数组 + 链表 / 红黑树）
  • C++11 起标准

核心点

点 答案
平均复杂度 O(1)
最坏 O(n)
冲突解决 链地址法
bucket 哈希桶
rehash 负载因子 > max_load_factor

✅ 面试杀手题

unordered_map 线程安全吗？

  • ❌ 不安全，需加锁或用 concurrent_hash_map

4️⃣ list / forward_list

底层

  • 双向链表 / 单向链表

特点

优点 缺点
任意位置 O(1) 插入删除 不支持随机访问
迭代器不失效 cache 不友好

✅ 常问

list 的 sort 是什么排序？

  • 归并排序

5️⃣ deque（双端队列）

底层结构

  • 分段连续内存 + 中央映射数组

特点

特性 说明
头尾插入 O(1)
随机访问 O(1)
扩容 不整体拷贝

✅ 隐藏考点

stack / queue 默认容器是？

  • deque

6️⃣ priority_queue（堆）

底层结构

  • vector + 堆算法（make_heap）

特点

点 说明
默认 大顶堆
小顶堆 greater<T>
插入 O(log n)
Top O(1)

✅ 常考

如何找第 K 大元素？

  • priority_queue（最小堆）

二、容器对比速查表（面试神器）

容器 底层 是否有序 查找 插入 稳定
vector 数组 ❌ O(n) O(1)~O(n) ✅
list 链表 ❌ O(n) O(1) ✅
map 红黑树 ✅ O(log n) O(log n) ✅
unordered_map 哈希 ❌ O(1) O(1) ❌
priority_queue 堆 ❌ O(1) top O(log n) ❌

三、STL 算法常考（）

1️⃣ sort（必考）

底层

  • Introsort
    • QuickSort + HeapSort + InsertionSort

特点

点 说明
平均 O(n log n)
最坏 O(n log n)
是否稳定 ❌
stable_sort ✅（归并）

✅ 常问

sort 为什么不用归并？

  • 归并要额外 O(n) 空间

2️⃣ find / count / binary_search

算法 前提 复杂度
find 无序 O(n)
binary_search 有序 O(log n)
lower_bound 有序 O(log n)

✅ 必会

3️⃣ erase-remove idiom（经典坑）

✅ 面试官想听：

remove 并不真的删除，只是移动元素

4️⃣ copy / transform / for_each

常考 lambda + STL

四、迭代器失效（高频致命题）

容器 插入 删除
vector 可能全部失效 后面失效
deque 首尾不失效 中间全失效
list 永不失效 仅当前失效
map 永不失效 仅当前失效

✅ 一句话总结：

连续内存容器最危险

五、面试官最爱追问 TOP 5

  1. map 和 unordered_map 选哪个？

    • 要顺序 → map
    • 要性能 → unordered_map

  2. vector 能用 memcpy 拷贝吗？

    • ❌ 非 POD 会崩

  3. emplace 比 push 好在哪？

    • 减少一次构造 + 拷贝

  4. STL 线程安全吗？

    • 读安全，写不安全

  5. 为什么少用 list？

    • cache miss 严重

六、30 秒面试速答模板

STL 容器里我最熟的是 vector、map 和 unordered_map。
vector 是连续内存，扩容成本高；map 用红黑树保证有序；unordered_map 用哈希表追求 O(1)。
sort 用的是 introsort，优先用快排，最坏情况退化成堆排。
