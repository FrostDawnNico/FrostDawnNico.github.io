一、模板 & 泛型（高频）

考点 一句话核心原理 展开原理记录
函数模板 编译器根据实参推导类型，生成具体函数 模板不是代码，而是代码生成器；template<typename T> 在编译期实例化
类模板 类本身参数化类型，延迟到使用时确定 类模板必须显式指定类型（除 CTAD）；每个不同类型都会生成新类
模板特化 为特定类型提供定制实现 全特化：template<> class A<int>；偏特化：限制部分参数
模板重载决议 普通函数 > 特化模板 > 通用模板 编译器选择最匹配且最特化的版本
SFINAE 替换失败不算错，只是淘汰该重载 std::enable_if、std::void_t；失败的重载不参与编译
Concepts（C++20） 对模板参数进行显式约束 concept Integral = std::is_integral_v<T>; 替代 SFINAE
可变参数模板 支持任意数量模板参数 template<typename... Args>；配合递归 / 折叠表达式
折叠表达式（C++17） 对参数包统一运算 (args + ...)、(... , args)；简化递归
模板实例化 用到才实例化 ODR 相关；显式实例化可控制编译体积
typename / template 关键字 告诉编译器这是类型或模板 typename T::value_type；T::template foo<U>()

二、泛型编程思想

考点 一句话核心原理 展开原理记录
泛型 vs 多态 泛型是编译期多态，虚函数是运行期多态 泛型零运行时开销；多态灵活但慢
静态多态 CRTP 在编译期绑定行为 Derived::foo() 被基类调用，无虚表
Duck Typing “只要像鸭子就行” 不要求继承，只要有对应接口
Policy-based Design 用模板组合行为策略 将算法拆成可替换模板参数

三、实用工具（STL & 类型工具）

1️⃣ type_traits（必考）

考点 一句话核心原理 展开原理记录
类型萃取 编译期获取类型属性 std::is_integral<T>、std::is_pointer<T>
类型变换 编译期修改类型 std::remove_reference、std::decay
std::void_t 检测表达式是否合法 常用于 SFINAE 检测接口存在性
if constexpr 编译期条件分支 避免无效代码实例化，替代 tag dispatch

2️⃣ 智能指针（高频）

考点 一句话核心原理 展开原理记录
unique_ptr 独占所有权，禁止拷贝 移动语义；零额外开销
shared_ptr 引用计数共享资源 控制块 + 原子计数；线程安全
weak_ptr 解决 shared_ptr 循环引用 不增加引用计数，需 lock()
make_shared 一次分配对象 + 控制块 减少内存碎片；异常安全
自定义 deleter 定制资源释放方式 lambda / 函数对象

3️⃣ STL 容器 & 算法

考点 一句话核心原理 展开原理记录
vector 扩容 2 倍 / 1.5 倍增长 重新分配 + 移动构造
迭代器失效 插入 / 删除可能使迭代器失效 vector 扩容全失效；list 仅当前失效
map vs unordered_map 红黑树 vs 哈希表 O(log n) vs 平均 O(1)
emplace 直接在容器中构造 避免不必要的拷贝 / 移动
algorithm + lambda 泛型算法解耦数据结构 std::sort, std::for_each

4️⃣ 其他实用工具

考点 一句话核心原理 展开原理记录
std::variant 类型安全的 union 访问需 std::visit
std::optional 表示“可能有值” 避免 nullptr / 特殊返回值
std::any 存储任意类型 类型擦除
std::tuple 编译期异构容器 配合 std::get、std::apply
std::function 类型擦除的可调用对象 有性能成本

四、一句话速记版（考前 5 分钟）

  • 模板 = 编译期代码生成器
  • SFINAE = 失败不报错，只是淘汰
  • Concepts = 模板参数的接口约束
  • 可变参数模板 + 折叠表达式 = 任意参数处理
  • unique_ptr = 独占，零开销
  • shared_ptr = 引用计数，注意循环引用
  • type_traits = 编译期类型反射
  • if constexpr = 编译期 if
